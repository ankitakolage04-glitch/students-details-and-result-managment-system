# Student Details and Result Management System

A simple Java-based console application to manage student details and calculate results.

## Features
- Add Student Details
- Store Student Information
- Enter Subject Marks
- Calculate Total Marks
- Calculate Percentage
- Display Student Result
- Simple Console-Based Interface
